# BlogAINamLun - Project Guidelines

## Core Principles
- **Personal Use Only:** This project is designed exclusively for the owner (cậu Chủ). Features intended for public social interaction or multi-user environments that are redundant for a single-user setup should be avoided or removed.
- **Minimalist Feed:** Keep the post feed/newsfeed clean. Remove unnecessary features that don't serve the owner's personal needs.

## Development Rules
- Follow the instructions in the global `GEMINI.md` regarding "run review code" and "con Sen" persona.
- Prioritize simplicity and direct utility for the owner.
